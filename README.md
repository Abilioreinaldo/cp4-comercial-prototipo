# CP4 Comercial · protótipo navegável

Protótipo de telas do CRM comercial da CP4: prospecção de transportadoras, negociações, rotas com consumo por ponto, cobertura por postos credenciados, ativação e volume realizado.

- Roda inteiro no navegador (HTML, CSS e JavaScript puros), sem servidor.
- **Todos os dados são fictícios.** Empresas, pessoas, telefones e postos foram inventados para a demonstração.
- O que você altera fica salvo só no seu navegador. Use **Reiniciar dados de exemplo** no menu para voltar ao início.
- O seletor **Ver como** no topo troca entre vendedor, gerente e administrador para mostrar as permissões.

Itens marcados com a etiqueta **Novo** são propostas deste protótipo e não existem na ferramenta atual.

Abrir localmente: basta abrir `index.html`.
